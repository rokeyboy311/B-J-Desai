# Architecture Overview

## Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS v4, React Router, Zod
- **Backend**: Node.js, Express, TypeScript, Zod
- **Database**: PostgreSQL (Render), Drizzle ORM
- **Auth**: JWT stored securely, bcryptjs for passwords

## Folder Structure
- `src/client/`: React frontend application
- `src/server/`: Express backend API
- `src/db/`: Drizzle schema and database connection
