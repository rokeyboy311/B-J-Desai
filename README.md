# Bina Enterprise Accounting Management

A professional full-stack web application for managing accounting records organized by location.

## Features
- Secure Authentication
- Location-based Record Management
- Advanced Filtering & Sorting
- Excel Export
- Mobile-First Dashboard

## Development Setup
1. Clone the repository
2. Run `npm install`
3. Setup PostgreSQL database and add `DATABASE_URL` to `.env`
4. Run `npm run dev` to start the full-stack server
