# REST API Documentation

## Auth
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

## Locations
- `GET /api/locations`
- `POST /api/locations`
- `GET /api/locations/:id`
- `PUT /api/locations/:id`
- `DELETE /api/locations/:id`

## Records
- `GET /api/records`
- `POST /api/locations/:id/records`
- `PUT /api/records/:id`
- `DELETE /api/records/:id`

## Export
- `GET /api/export/excel`
